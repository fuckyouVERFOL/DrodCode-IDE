# DrodCode IDE User Guide 📘

Welcome to **DrodCode IDE**, a full-featured development environment designed for modern software engineering across Windows, macOS, and Linux.

---

## 1. Getting Started

### Opening a Project
1. Launch DrodCode IDE.
2. Click the **Explorer** icon in the left ActivityBar or press `Ctrl+K Ctrl+O`.
3. Select any local folder to load your codebase.

### Editor Features
- **Language Support**: Instant syntax highlighting for JS, TS, Python, Java, C++, Go, Rust, PHP, C#, HTML, CSS, SQL, JSON, YAML, XML, Markdown, Shell, and 15+ more languages.
- **IntelliSense**: Press `Ctrl+Space` for autocompletion.
- **Code Formatting**: Press `Shift+Alt+F` to format the active document.
- **Diff Comparison**: Click any modified file in Git view to open side-by-side visual diff.

---

## 2. Integrated Terminal

- Press `Ctrl+` ` (backtick) to toggle the bottom terminal.
- Click `+` to open multiple terminal tabs with PowerShell, Bash, Zsh, or CMD.

---

## 3. Git Version Control

1. Click the **Source Control** icon on the ActivityBar (`Ctrl+Shift+G`).
2. Review modified and untracked files.
3. Click `+` to stage changes, type a commit message, and click **Commit**.
4. Use Push/Pull icons in the top right to synchronize with GitHub/GitLab.

---

## 4. DrodCode AI Assistant

- Open the **AI Chat** tab in the sidebar or bottom panel.
- Ask question about your code (e.g. "Explain this function" or "Create a JSON parser function").
- Use inline AI suggestions to complete repetitive boilerplate code.
